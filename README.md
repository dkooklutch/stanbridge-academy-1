# Stanbridge Student Support Hub

An internal staff workspace for documenting student support observations, maintaining learning profiles, coordinating follow-ups, and preparing weekly family summaries.

## Run Locally

Open `index.html` directly in a browser, or run a static server from this folder:

```bash
python3 -m http.server 4177
```

Then visit `http://127.0.0.1:4177/`.
