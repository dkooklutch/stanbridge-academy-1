# Stanbridge Student Support Hub

Teacher-only prototype/MVP for documenting student support observations, learning profiles, collaboration notes, pattern insights, and Weekly Spark Reports.

## Run Locally

Open `index.html` directly in a browser, or run a static server from this folder:

```bash
python3 -m http.server 4177
```

Then visit `http://127.0.0.1:4177/`.
